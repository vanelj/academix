# Referencias de base de datos

Estos archivos son copias de consulta para el desarrollo. No forman parte del código de la aplicación y no se ejecutan automáticamente.

- `../base_datos_plataforma_cursos.sql`: esquema V4 del proyecto.

La V4 pegada en el chat coincide con el archivo V4 ya existente en `docs/` (ignorando diferencias de saltos de línea). Se conserva una sola copia para evitar tener dos versiones de referencia que puedan divergir.
